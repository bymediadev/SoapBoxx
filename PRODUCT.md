# SoapBoxx — Product Definition

## What SoapBoxx is

SoapBoxx is a podcast production system that helps creators improve every episode through recording, transcription, and structured AI feedback.

It is not just a recording tool. It is a **closed-loop improvement system** for spoken content.

## Core value proposition

Most podcast tools help you record content.

SoapBoxx helps you:

> Record → Understand → Improve → Repeat

## Core loop

1. Record podcast episode
2. Transcribe audio into structured text
3. Analyze content with AI
4. Extract insights, questions, and patterns
5. Provide actionable feedback
6. Improve next episode using feedback

## Target user

- Independent podcasters
- Small podcast teams
- Content creators who publish regularly
- Interview-based shows

## What SoapBoxx is NOT

- Not a full audio DAW (like Ableton or Audacity)
- Not a video editing platform
- Not a social media distribution tool
- Not a generic AI chatbot wrapper

## Success metric (product-level)

A user should be able to say:

> "My episodes improve measurably after using SoapBoxx for 3–5 recordings."

## Product pillars

1. Recording quality and simplicity
2. AI transcription and structuring
3. Feedback-driven improvement loop
4. **Host-ready questions** — framed for the mic, not raw transcript fragments (see `backend/question_framing.py`)
