SoapBoxx Demo — 15-Minute Quickstart

Follow the pictures in order. Latest build: demo-v1.2.3

~12–15 min with API key

You do not need Python. You do need to extract the full zip before launching.

Step 1 — Download (~2 min)

  1. Open the v1.2.3 release page.
  2. Under Assets, click SoapBoxx-Production-Studio-Demo-v1.2.3.zip.

Step 2 — Extract the whole zip (~2 min)

Important: Do not double-click the .bat from inside WinRAR. Extract everything first.
  1. Right-click the zip → Extract All…
  2. Extract to e.g. C:\SoapBoxx-Demo\
  3. Open folder SoapBoxx-Production-Studio-Demo-v1.2.3

Step 3 — Norton (only if the app fails)

If the app won't start or the SoapBoxx tab is empty:

  1. Add an antivirus exclusion for your extracted folder.
  2. Restore any quarantined SoapBoxxProductionStudioDemo files.

Step 4 — Launch (~1 min)

  1. Double-click Launch SoapBoxx Production Studio Demo.bat
  2. If SmartScreen appears: More info → Run anyway

Step 5 — API key (~3 min, for live transcript)

  1. Open Settings tab
  2. Paste OpenAI key (sk-…) → choose OpenAI → Save

Or: put a .env file from your host in this folder and restart the app.

Step 6 — Smoke test (~5 min)

  1. SoapBoxx tab → Start Recording
  2. Speak 10–15 seconds → Stop Recording
  3. Check Live Transcript and guest questions
