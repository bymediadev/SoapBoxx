SoapBoxx Demo — quick start (after unzip)
==========================================

1) Install Python 3.8+ if you don’t have it: https://www.python.org/downloads/
   On Windows, check “Add Python to PATH” during install.

2) Run ONE of these from this folder (SoapBoxx-Demo):

   Windows:     Double-click  setup_and_run.bat
                (or run setup_and_run.ps1 in PowerShell)

   Mac:         Double-click  setup_and_run.command
                (first time: right-click → Open, or run: chmod +x setup_and_run.command)

   Linux:       In a terminal:  chmod +x setup_and_run.sh && ./setup_and_run.sh

   That installs dependencies and starts the app.

3) Full guide: docs/README_DEMO.md
